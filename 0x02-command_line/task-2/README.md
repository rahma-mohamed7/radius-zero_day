Task 2: File and Directory Management

Commands Practised

- "mkdir" - Creates directories.
- "touch" - Creates empty files.
- "echo" - Writes text into files.
- "cat" - Displays file contents.
- "head" - Displays the first lines.
- "tail" - Displays the last lines.
- "wc -l" - Counts lines.
- "cp" - Copies files.
- "mv" - Moves or renames files.
- "rm" - Removes files.
- "ls -l" - Displays file permissions.

Explanation of Commands

1. "mkdir": Creates new directories.
2. "touch": Creates empty files.
3. "cp": Copies files from one location to another.
4. "mv": Moves or renames files.
5. "rm": Removes files.

Difference Between > and >>

- ">" writes new content and replaces existing content.
- ">>" adds new content without deleting existing content.

File Permissions Observation

I used "ls -l" to inspect file permissions.

I observed that my files had "-rw-------" permissions.

This means the owner can read and write the files, while the group and others have no permissions.

Conclusion

I practised creating, inspecting, copying, moving, renaming, and removing files and directories using Linux commands.
