# Task 1: Linux Terminal Navigation

## Commands Practised

1. pwd - Displays the current working directory.
2. whoami - Displays the current username.
3. hostname - Displays the computer name.
4. date - Displays the current date and time.
5. ls - Lists files and directories.
6. ls -l - Displays detailed file information.
7. ls -la - Displays hidden files and detailed information.
8. cd .. - Moves to the parent directory.
9. cd - - Returns to the previous directory.
10. cd ~ - Moves to the home directory.
11. mkdir -p - Creates directories.
12. touch - Creates empty files.
13. find - Searches for files and directories.

## What I Learned

I learned how to navigate the Linux filesystem, identify my current location and username, explore the Linux environment, create directories and files, and verify my work using Linux commands.
